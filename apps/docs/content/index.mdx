## Built around useful answers

Kronik keeps its scope explicit, bounded, and easy to consume.

- **[Commit feed](/api-reference/activity/v1-activity-commits)** — Browse matching public commits with authenticated, user-bound cursor pagination.
- **[Activity summary](/api-reference/activity/v1-activity-summary)** — Aggregate changes and repository language bytes over a precise UTC activity window.
- **[Contribution streaks](/api-reference/activity/v1-activity-streak)** — Evaluate current and longest streaks over GitHub's trailing 365-day calendar.
